1. INTRODUCTION                                         *adhd-structure-intro*

adhd-structure.nvim is an assistive workflow plugin designed to mitigate
executive dysfunction, time blindness, and cognitive inertia during intensive
work or study sessions.

Features:
- Flowmodoro Timer: A stopwatch counting up during flow, automatically
  calculating break times based on a 45:15 (or custom) ratio.
- Always-on-Top Floating HUD: A minimal top-right floating window.
  Border glows green during focus sessions and red during breaks.
  Window is unfocusable (`focusable = false`) to never interrupt typing.
- 60-second RAM-Dump: A fast save-state protocol to capture active working
  memory before leaving the keyboard or breaking hyperfocus.

==============================================================================
2. REQUIREMENTS                                 *adhd-structure-requirements*

- Neovim >= 0.9.0 (requires floating window `title` and `vim.uv`/`vim.loop`).
- Nerd Font (optional, recommended for icon glyphs).

==============================================================================
3. INSTALLATION                                 *adhd-structure-installation*

Using lazy.nvim: >lua
  {
    "Phrozenn1/adhd-structure.nvim",
    event = "VeryLazy",
    opts = {},
  }
<
Using mini.deps: >lua
  MiniDeps.add({ source = "Phrozenn1/adhd-structure.nvim" })
  require("adhd-structure").setup()
<
Using vim-plug: >vim
  Plug 'Phrozenn1/adhd-structure.nvim'
  " In lua configuration:
  lua require('adhd-structure').setup()
<
Manual (built-in Neovim package): >sh
  git clone https://github.com/Phrozenn1/adhd-structure.nvim.git \
    "${XDG_DATA_HOME:-$HOME/.local/share}/nvim/site/pack/plugins/start/adhd-structure.nvim"
<

==============================================================================
4. COMMANDS                                         *adhd-structure-commands*

:AdhdFlowmodoroToggle                            *:AdhdFlowmodoroToggle*
    Cycles state: Idle -> Focus -> Break -> Idle.
    Calculates break time based on ratio when exiting focus.

:AdhdFlowmodoroReset                              *:AdhdFlowmodoroReset*
    Stops active timer, resets counters, and closes the floating HUD.

:AdhdFlowmodoroHud                                  *:AdhdFlowmodoroHud*
    Toggles the floating HUD window visibility without stopping background
    timers.

:AdhdRamDump                                              *:AdhdRamDump*
    Inserts the 3-line RAM-dump template below the cursor (or on an empty
    line) and starts insert mode right after `[NÅ]: `.

==============================================================================
5. DEFAULT MAPPINGS                                 *adhd-structure-mappings*

The following keymaps are mapped by default in normal mode:

  <leader>rf    |:AdhdFlowmodoroToggle|
  <leader>rF    |:AdhdFlowmodoroReset|
  <leader>rh    |:AdhdFlowmodoroHud|
  <leader>rd    |:AdhdRamDump|

To customize or disable keymaps, set `keymaps = false` or provide your own
mapping table in `opts.keymaps`.

==============================================================================
6. CONFIGURATION                               *adhd-structure-configuration*

Pass options table to `setup()`: >lua
  require("adhd-structure").setup({
    -- Focus to break ratio (default 45:15)
    ratio = {
      focus = 45,
      rest = 15,
    },
    hud = {
      enabled = true,
      row = 1,
      col_offset = -1,  -- Offset from right edge
      width = 24,
      height = 1,
      border = "rounded",
      zindex = 100,
      colors = {
        focus_border = "#98c379", -- Green border in focus
        focus_fg = "#98c379",
        rest_border = "#e06c75",  -- Red border in break
        rest_fg = "#e06c75",
        title_fg = "#abb2bf",
      },
    },
    ramdump = {
      template = {
        "--- PAUSE / SAVE-STATE ---",
        "[NÅ]:        ",
        "[STATUS]:    ",
        "[NESTE STEG]: ",
        "---------------------------",
      },
      cursor_line_offset = 2,
      cursor_col = 13,
    },
    notifications = {
      enabled = true,
      remind_ramdump = true,
    },
    keymaps = {
      ramdump = "<leader>rd",
      flowmodoro_toggle = "<leader>rf",
      flowmodoro_reset = "<leader>rF",
      hud_toggle = "<leader>rh",
    },
  })
<

==============================================================================
7. RAM-DUMP PROTOCOL                                 *adhd-structure-ramdump*

A quick 60-second cognitive save-state to freeze working memory before
leaving your chair or breaking focus: >markdown
  --- PAUSE / SAVE-STATE ---
  [NÅ]:        TMA4401 - Assignment 7, task 3b
  [STATUS]:    Split using partial fraction; need B and C
  [NESTE STEG]: Solve system of equations for B & C
  ---------------------------
<

==============================================================================
8. FLOWMODORO CONCEPT                             *adhd-structure-flowmodoro*

Standard Pomodoro forcibly stops you after 25 minutes. Flowmodoro counts UP
during focus, allowing you to ride hyperfocus naturally. When mental stamina
drops, press `<leader>rf`: a break duration equal to 1/3 (ratio 45:15) of
your focus time is earned and starts counting down automatically.
